# Security

This repository is an experimental single-key demonstration with a default CPU backend and an experimental CUDA backend. Its keys, plaintext inputs and locally calculated references are held in the same process; it is not a hardened deployment or decentralized key-management system. See `docs/limitations.md` for the proof statement and numerical boundaries.

## Supported versions

Security fixes are considered for the current development version. There is no maintained release or long-term support policy yet.

## Reporting

The team has not yet published a private security contact or response timeline. Please avoid including exploitable details, keys or sensitive data in public issues. A private reporting channel and disclosure policy will be added once the team has supplied and verified them.
